من نحن

DVLPR Tools منصة عربية لأدوات المطورين، تعمل مباشرة في المتصفح بدون خوادم وبلا تسجيل.

هدف المنصة

نركّز على الأدوات التي توفر وقتاً في المهام المتكررة: تنسيق الأكواد، التحقق من صحتها، وفحص البيانات. الأولوية دائماً لوضوح النتيجة وسهولة نسخها، بدل الواجهات المعقدة.

مبادئنا

خصوصية افتراضية

نفضّل المعالجة داخل المتصفح كلما أمكن، حتى لا تمسّ بياناتك أي خادم.

أداء حقيقي

صفحات خفيفة وسريعة، مع lazily-loaded وثبات في التخطيط.

بسيطة بالعربية

واجهة عربية واضحة ومن اليمين إلى اليسار منذ البداية.

الأدوات المتاحة

  • منسق ومصحح JSON — نسّق، صغّر، فرز المفاتيح، تحقق وانسخ JSON بسهولة مع رسائل أخطاء واضحة وموضع دقيق للخطأ.
  • محول JSON إلى TypeScript — حوّل بيانات JSON إلى TypeScript Interfaces جاهزة للاستخدام في React وNext.js وNode.js، مع تسمية الواجهات وترتيبها تلقائياً.
  • محلّل JWT — افكّ واقرأ محتوى JSON Web Token داخل متصفحك: الـ Header والـ Payload والتوقيع، مع قراءة تواريخ الإصدار والانتهاء والتحقق من حالة الصلاحية.
  • ترميز وفك ترميز Base64 — حوّل النص إلى Base64 أو أعد فكّه إلى نص عادي مع دعم كامل للعربية وUTF-8، نسخ وتحميل فوري، ومعالجة داخل المتصفح دون أي خادم.
  • مولّد UUID — ولّد معرّفات UUID v4 عشوائية بضغطة واحدة، حتى 100 معرّف في المرة، مع نسخ كل النتيجة أو كل معرّف على حدة وتحميلها كملف نصي.
  • مختبر Regex — اختبر Regular Expressions مباشرة وشاهد كل التطابقات ومجموعات الالتقاط ومواقعها داخل النص، مع معاينة النتيجة وتجربة الاستبدال.
  • محوّل Unix Timestamp — حوّل Unix Timestamp إلى تاريخ ووقت، أو حوّل التاريخ إلى Timestamp بالثواني أو المللي ثانية، مع عرض التوقيت المحلي و UTC ومدة بقاء التاريخ من الآن.
  • محوّل الألوان — حوّل الألوان بين HEX و RGB و HSL مع معاينة مباشرة، نسخ أي قيمة بضغطة، مولّد ألوان عشوائي، وفحص نسبة التباين مع النص حسب معيار WCAG.
  • مولّد الهاش — أنشئ Hash للنص بخوارزميات MD5 و SHA-1 و SHA-256 و SHA-512 داخل متصفحك مباشرة، مع تنبيه أمني يوضّح الفرق بين الهاش والتشفير.
  • منسّق SQL — نسّق استعلامات SQL و اضغطها لتصبح أسهل في القراءة، مع كسر سطري ذكي لـ SELECT و JOIN و CASE، ومعاينة ملوّنة، وتحميل الملف.
