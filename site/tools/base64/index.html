ترميز وفكّ ترميز Base64

حوّل النص إلى Base64 أو أعد فكّه إلى نص عادي مع دعم كامل للعربية وUTF-8، نسخ وتحميل فوري، ومعالجة داخل المتصفح دون أي خادم.

كيفية الاستخدام

اختر ترميز ثم الصق نصك واضغط زر التحويل. وللعكس اختر فكّ الترميز والصق قيمة Base64. يمكنك الضغط على استخدم الناتج كمدخل لمتابعة العملية في الاتجاه المعاكس دون نسخ يدوي.

مثال عملي

النص  :  مرحبا بك في أدواتنا 🚀
Base64: 2YXYsdit2KjYpyDYqNmDINmB2Yog2KPYr9mI2KfYqtmG2Kcg8J+agA==

حالات شائعة

  • - و_ يظهران في بعض القيم وهذا ترميز Base64URL وليس خطأ — وهو المستخدم في JWT.
  • القيم المنتهية بـ= هي رموز حشو، ولا يجوز حذفها في الحالة العادية.
  • إذا فشل فكّ الترميز فالقيمة غالباً ليست Base64 أصلاً، أو أنها ثنائية لا نصية.

لماذا Base64؟

Base64 تحوّل البيانات الثنائية إلى أحرف نصية آمنة في JSON وروابط URL وترويسات HTTP و Data URLs. وهي ليست تشفيراً — أي شخص يملك النص المُرمَّز يستطيع استرجاع الأصل.

حدود الأداة

  • مخصّصة للنصوص فقط ولا تدعم Data URLs مثل data:image/png;base64,….
  • لا تنفّذ الترميز الثنائي الخام، وهو أقل شيوعاً في الاستخدام اليومي.
  • لا تتجاهل المسافات داخل النص لأنها جزء من المحتوى وتُرمّز كما هي.

ملاحظة أمنية

كل المعالجة تتم محلياً عبر TextEncoder وbtoa. لا يوجد أي طلب شبكة، لذا لا تغادر بياناتك جهازك.

مزايا الأداة

  • ترميز وفكّ ترميز في واجهة واحدة بزر تبديل
  • دعم كامل للنصوص العربية والرموز التعبيرية عبر UTF-8
  • استخدام الناتج كمدخل بضغطة واحدة لمتابعة الجولة التالية
  • نسخ الناتج أو تنزيله كملف نصي
  • تنبيه دقيق عند إدخال Base64 غير صالح

أسئلة شائعة

هل تُرسل نصوصي إلى خادم؟+

لا. الترميز يتم داخل متصفحك عبر TextEncoder و btoa مباشرة، ولا تغادر بياناتك جهازك إلى أي خادم.

ما الذي لا تدعمه الأداة؟+

لا تدعم Data URL مثل data:image/png;base64,... ولا الترميز الثنائي الخام. الأداة مخصّصة للنصوص فقط، وهذا أكثر شيوعاً في الاستخدام اليومي.

لماذا يفشل فكّ الترميز أحياناً؟+

السبب غالباً قيمة ليست Base64 أصلاً، أو بيانات ثنائية بترميز غير UTF-8. الأداة تطلب UTF-8 صراحةً حتى لا يفسد النص العربي بصمت.

منسق ومصحح JSON

نسّق، صغّر، فرز المفاتيح، تحقق وانسخ JSON بسهولة مع رسائل أخطاء واضحة وموضع دقيق للخطأ.

محول JSON إلى TypeScript

حوّل بيانات JSON إلى TypeScript Interfaces جاهزة للاستخدام في React وNext.js وNode.js، مع تسمية الواجهات وترتيبها تلقائياً.

محلّل JWT

افكّ واقرأ محتوى JSON Web Token داخل متصفحك: الـ Header والـ Payload والتوقيع، مع قراءة تواريخ الإصدار والانتهاء والتحقق من حالة الصلاحية.

مولّد UUID

ولّد معرّفات UUID v4 عشوائية بضغطة واحدة، حتى 100 معرّف في المرة، مع نسخ كل النتيجة أو كل معرّف على حدة وتحميلها كملف نصي.

مختبر Regex

اختبر Regular Expressions مباشرة وشاهد كل التطابقات ومجموعات الالتقاط ومواقعها داخل النص، مع معاينة النتيجة وتجربة الاستبدال.

محوّل Unix Timestamp

حوّل Unix Timestamp إلى تاريخ ووقت، أو حوّل التاريخ إلى Timestamp بالثواني أو المللي ثانية، مع عرض التوقيت المحلي و UTC ومدة بقاء التاريخ من الآن.

محوّل الألوان

حوّل الألوان بين HEX و RGB و HSL مع معاينة مباشرة، نسخ أي قيمة بضغطة، مولّد ألوان عشوائي، وفحص نسبة التباين مع النص حسب معيار WCAG.

مولّد الهاش

أنشئ Hash للنص بخوارزميات MD5 و SHA-1 و SHA-256 و SHA-512 داخل متصفحك مباشرة، مع تنبيه أمني يوضّح الفرق بين الهاش والتشفير.

منسّق SQL

نسّق استعلامات SQL و اضغطها لتصبح أسهل في القراءة، مع كسر سطري ذكي لـ SELECT و JOIN و CASE، ومعاينة ملوّنة، وتحميل الملف.
