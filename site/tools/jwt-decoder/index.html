محلّل JWT

افكّ واقرأ محتوى JSON Web Token داخل متصفحك: الـ Header والـ Payload والتوقيع، مع قراءة تواريخ الإصدار والانتهاء والتحقق من حالة الصلاحية.

كيفية الاستخدام

الصق التوكن في المربع، ثم اضغط فكّ وتحليل JWT. سيظهر الـ Header والـ Payload بتنسيق JSON، إضافة إلى التوقيع الخام وتواريخ الصلاحية.

مثال على Claims شائعة

{
  "sub": "1234567890",
  "name": "John Doe",
  "iat": 1516239022,
  "exp": 1516825822,
  "iss": "https://example.com",
  "aud": "my-app"
}

الحقول المهمّة

  • exp — وقت الانتهاء، وبعده يصبح التوكن غير صالح.
  • iat — وقت الإصدار.
  • nbf — لا يُقبل التوكن قبل هذا الوقت.
  • iss وaud — الجهة المصدِرة والجمهور المقصود.

ما لا تفعله هذه الأداة

الأداة تقرأ المحتوى فقط. للتحقق من صحة التوقيع تحتاج إلى المفتاح السري الذي وقّع به الخادم، وهو لا يكون متاحاً في المتصفح أصلاً.

الأدوات التي تدّعي التحقق من التوقيع دون مفتاح هي مضلّلة. إن احتجت تحقّقاً فعلياً، استخدم مكتبات الخادم مثل jsonwebtoken أو pyjwt.

ملاحظات أمنية

  • لا تُدخل توكنات تحتوي على أسرار أو بيانات شخصية حساسة.
  • التوكن ليس وسيلة تشفير — محتواه قابل للقراءة من أي شخص يملك التوكن.
  • لا تشارك توكنات وصول حقيقية مع أي أداة خارجية.

مزايا الأداة

  • فكّ Base64URL لـ Header وPayload وعرضهما بتنسيق JSON
  • قراءة تواريخ iat وexp وnbf بالتوقيت المحلي
  • تحديد حالة الصلاحية: منتهية أم سارية
  • نسخ أي جزء من التوكن بنقرة واحدة
  • تنبيه أمني واضح بأن الأداة لا تتحقق من التوقيع

أسئلة شائعة

هل تتحقق الأداة من صحة التوقيع؟+

لا. الأداة تقرأ المحتوى فقط ولا تملك المفتاح السري الذي يلزم للتحقق من التوقيع. أي أداة تدّعي أنها تفعل ذلك دون مفتاح هي مضلّلة.

لماذا يظهر خطأ عند لصق التوكن؟+

تأكد أن التوكن يتكوّن من ثلاثة أجزاء مفصولة بنقاط، وأن جزأيه الأول والثاني مرمّزان بـ Base64URL. بعض الأدوات تحذف رموز الحشو في نهاية الجزء.

هل يُرسل التوكن إلى خادم؟+

لا. كل الفكّ يتم داخل متصفحك عبر JavaScript، ولا تغادر البيانات جهازك.

منسق ومصحح JSON

نسّق، صغّر، فرز المفاتيح، تحقق وانسخ JSON بسهولة مع رسائل أخطاء واضحة وموضع دقيق للخطأ.

محول JSON إلى TypeScript

حوّل بيانات JSON إلى TypeScript Interfaces جاهزة للاستخدام في React وNext.js وNode.js، مع تسمية الواجهات وترتيبها تلقائياً.

ترميز وفك ترميز Base64

حوّل النص إلى Base64 أو أعد فكّه إلى نص عادي مع دعم كامل للعربية وUTF-8، نسخ وتحميل فوري، ومعالجة داخل المتصفح دون أي خادم.

مولّد UUID

ولّد معرّفات UUID v4 عشوائية بضغطة واحدة، حتى 100 معرّف في المرة، مع نسخ كل النتيجة أو كل معرّف على حدة وتحميلها كملف نصي.

مختبر Regex

اختبر Regular Expressions مباشرة وشاهد كل التطابقات ومجموعات الالتقاط ومواقعها داخل النص، مع معاينة النتيجة وتجربة الاستبدال.

محوّل Unix Timestamp

حوّل Unix Timestamp إلى تاريخ ووقت، أو حوّل التاريخ إلى Timestamp بالثواني أو المللي ثانية، مع عرض التوقيت المحلي و UTC ومدة بقاء التاريخ من الآن.

محوّل الألوان

حوّل الألوان بين HEX و RGB و HSL مع معاينة مباشرة، نسخ أي قيمة بضغطة، مولّد ألوان عشوائي، وفحص نسبة التباين مع النص حسب معيار WCAG.

مولّد الهاش

أنشئ Hash للنص بخوارزميات MD5 و SHA-1 و SHA-256 و SHA-512 داخل متصفحك مباشرة، مع تنبيه أمني يوضّح الفرق بين الهاش والتشفير.

منسّق SQL

نسّق استعلامات SQL و اضغطها لتصبح أسهل في القراءة، مع كسر سطري ذكي لـ SELECT و JOIN و CASE، ومعاينة ملوّنة، وتحميل الملف.
