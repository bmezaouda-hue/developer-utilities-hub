مدقّق SQL

تحقق من صحة جمل SQL وفق لهجة standard أو mysql أو postgres، مع تحديد موضع الأخطاء النحوية وعدد الجمل والرموز.

التحقق يتم محلياً داخل متصفحك دون إرسال أي شيء إلى أي خادم. هذا محلّل نحوي مبسّط يتفحص توازن الأقواس والسلاسل والتعليقات وكلمات البداية، وليس بديلاً عن محرك قاعدة بيانات حقيقي.

كيفية الاستخدام

الصق استعلام SQL ليتحقق المدقق من صحة الصياغة وتوازن الأقواس والفاصلات. يعرض موضع الخطأ ويساعدك على تصحيح الجملة قبل تنفيذها.

الخصوصية والأمان

يتم التحقق محلياً دون الاتصال بقاعدة بيانات أو خادم، فلا تُنفّذ ولا تُرسل استعلاماتك. لا نحتفظ بمحتواها ولا بمخططك.

مزايا الأداة

  • ثلاث لهجات: standard و mysql و postgres
  • كشف الأخطاء النحوية بموضعها
  • عدّ الجمل والرموز في الاستعلام
  • تنبيه للأقواس غير المتوازنة
  • دعم النصوص والتعليقات
  • تقرير واضح بالنتيجة

أسئلة شائعة

ما معنى اللهجات المدعومة؟+

standard للصيغة القياسية، وmysql لقواعد MySQL وMariaDB، وpostgres لـ PostgreSQL، ولكل منها قواعد وجمل خاصة مثل RETURNING أو LIMIT.

هل يعني النجاح أن الاستعلام سيعمل؟+

التحقق نحوي أساساً، أي أن الصياغة صحيحة، لكنه لا يضمن وجود الجداول أو الأعمدة في قاعدة بياناتك الفعلية.

هل تنفّذ الأداة الاستعلام؟+

لا، الأداة تحلل النص فقط ولا تتصل بأي قاعدة بيانات ولا تنفّذ أي جملة.

هل تُرسل الاستعلامات إلى خادم؟+

لا. التحقق يتم محلياً داخل متصفحك دون أي طلب شبكة.

منسق ومصحح JSON

نسّق، صغّر، فرز المفاتيح، تحقق وانسخ JSON بسهولة مع رسائل أخطاء واضحة وموضع دقيق للخطأ.

محول JSON إلى TypeScript

حوّل بيانات JSON إلى TypeScript Interfaces جاهزة للاستخدام في React وNext.js وNode.js، مع تسمية الواجهات وترتيبها تلقائياً.

مصغّر JSON

صغّر JSON بحذف كل المسافات غير الضرورية في سطر واحد، مع حفظ نصوص القيم كما هي، والتحقق من توازن الأقواس، ومقارنة الحجم قبل وبعد.

منسّق YAML

نسّق ملفات YAML بإزاحة موحّدة من مسافتين لكل مستوى، مع تحقق من توازن الأقواس في flow والاقتباسات وأخطاء التبويب، وفكّ تشابك البنى المتداخلة.

محوّل YAML و JSON

حوّل بين YAML و JSON في الاتجاهين بضغطة واحدة، مع كشف تلقائي لصيغة الإدخال وإظهار الأخطاء بموضع دقيق. كل المعالجة تتم داخل متصفحك دون إرسال بياناتك.

محوّل XML و JSON

حوّل XML إلى JSON والعكس مع التعامل الذكي مع سمات العناصر والنصوص والمساحات الاسمية، والحفاظ على بنية البيانات كما هي. المعالجة كلها تجري داخل متصفحك.

محوّل CSV و JSON

حوّل CSV إلى JSON مع فاصل مخصص وصف ترويسة اختياري، أو حوّل مصفوفة JSON إلى CSV منسّق، مع حدود أمان على الحجم للحفاظ على أداء المتصفح.

مولّد JSON Schema

ولّد مخطط JSON Schema تلقائياً من عينة بيانات، مع استنتاج الأنواع وتحديد المفاتيح المطلوبة، وتغطية الكائنات والمصفوفات المتداخلة.

مدقّق JSON Schema

تحقق من بيانات JSON مقابل مخطط JSON Schema مع فحص الحقول المطلوبة والأنواع والحدود والأنماط والخصائص الإضافية، وعرض مسارات الأخطاء بالعربية.

محلّل JWT

افكّ واقرأ محتوى JSON Web Token داخل متصفحك: الـ Header والـ Payload والتوقيع، مع قراءة تواريخ الإصدار والانتهاء والتحقق من حالة الصلاحية.

مولّد الهاش

أنشئ Hash للنص بخوارزميات MD5 و SHA-1 و SHA-256 و SHA-512 داخل متصفحك مباشرة، مع تنبيه أمني يوضّح الفرق بين الهاش والتشفير.

مولّد JWT

ولّد JSON Web Token موقّعاً بخوارزمية HS256 أو غير موقّع (none) عبر Web Crypto في المتصفح، مع إدخال الحمولة والمطالبات القياسية.

مولّد SHA

احسب بصمات SHA-256 و SHA-384 و SHA-512 عبر Web Crypto الأصلي في المتصفح، مع عرض الناتج السداسي كاملاً ونسخه فوراً.

مولّد HMAC

احسب كود HMAC برسالة ومفتاح سري بثلاث خوارزميات SHA عبر Web Crypto، لاستخدامه في توقيع الردود والتحقق من سلامتها.

مولّد كلمات المرور

ولّد كلمات مرور قوية بضوابط دقيقة للأحرف الكبيرة والصغيرة والأرقام والرموز، مع حساب القوة بالبتات وتقييم فوري للجودة.

مولّد عبارات المرور

ولّد عبارات مرور من قائمة كلمات عربية أو ممتزجة مع فواصل وخيارات إضافية، لتحصل على عبارة قوية يسهل تذكّرها.

ترميز وفك ترميز Base64

حوّل النص إلى Base64 أو أعد فكّه إلى نص عادي مع دعم كامل للعربية وUTF-8، نسخ وتحميل فوري، ومعالجة داخل المتصفح دون أي خادم.

ترميز وفكّ ترميز الروابط (URL)

حوّل النص أو الروابط إلى صيغة URL آمنة (Percent-Encoding) أو أعد فكّها إلى نص مقروء، مع دعم كامل للعربية وUTF-8 ومعالجة داخل المتصفح دون إرسال بيانات إلى خادم.

ترميز الصور Base64

حوّل أي صورة إلى Base64 Data URL لاستخدامها مباشرة داخل HTML أو CSS، أو أعد تحويل Data URL إلى صورة، مع معاينة فورية وحدود على الحجم.

مولّد Data URI

ولّد Data URI من نص أو ملف بترميز Base64 أو UTF-8، وافكّ أي Data URI معروض لاستعادة النص أو الملف الأصلي، مع نسخ وتنزيل فوري.

مختبر Regex

اختبر Regular Expressions مباشرة وشاهد كل التطابقات ومجموعات الالتقاط ومواقعها داخل النص، مع معاينة النتيجة وتجربة الاستبدال.

مُقارن النصوص

قارن بين نصين سطراً بسطر وأبرز الأسطر المحذوفة والمضافة فقط، مع إحصائيات التغيير وقابلية نسخ النتيجة بصيغة +/−.

معاينة Markdown

اكتب Markdown وشاهد النتيجة الحية: العناوين والقوائم والاقتباسات والكود والروابط، مع تنقية الوسوم والروابط غير الآمنة، دون إرسال المحتوى.

مولّد Regex

ابنِ تعبيرات Regex من قوالب جاهزة مثل البريد الإلكتروني والهاتف والرابط والتاريخ، واختبرها فورياً على نصك مع إحصاء المطابقات.

محوّل حالة النص

حوّل النص بين أنماط التسمية الشائعة مثل camelCase و snake_case و kebab-case والأحرف الكبيرة و Title Case، بنقرة واحدة.

منظّف النص

نظّف النص من المسافات المكررة والأسطر الفارغة والمحارف الخفية، ووحّد الأرقام وصيغ الأحرف العربية والحالة والترقيم.

منسّق SQL

نسّق استعلامات SQL و اضغطها لتصبح أسهل في القراءة، مع كسر سطري ذكي لـ SELECT و JOIN و CASE، ومعاينة ملوّنة، وتحميل الملف.

مولّد استعلامات SQL

ابنِ جملة SELECT بصرياً بتحديد الأعمدة والجداول وشروط WHERE والترتيب والحد وخيار المميز، مع اقتباس المعرفات تلقائياً.

مصغّر SQL

صغّر استعلامات SQL بحذف التعليقات والمسافات والأسطر الزائدة، مع خيار الإبقاء على التعليقات وإحصاء حجم التوفير بالبايت.

محوّل الألوان

حوّل الألوان بين HEX و RGB و HSL مع معاينة مباشرة، نسخ أي قيمة بضغطة، مولّد ألوان عشوائي، وفحص نسبة التباين مع النص حسب معيار WCAG.

منسّق HTML

نسّق كود HTML ورتّبه بمسافات بادئة متّسقة وبنية مقروءة، أو صغّره في سطر واحد، مع نسخ وتحميل فوري ومعالجة داخل المتصفح دون إرسال بيانات إلى خادم.

منسّق CSS

نسّق كود CSS بإزاحة متّسقة وقواعد مقروءة، وحافظ على التعليقات والقيم المكتوبة داخل علامات الاقتباس، مع نسخ وتحميل فوري ومعالجة داخل المتصفح دون إرسال أي شيء إلى خادم.

منسّق JavaScript

نسّق كود JavaScript ببنية مقروءة وإزاحة متّسقة بحجمين، مع دعم الدوال والفئات والكائنات والقوالب، وتنبيه فوري بالأخطاء النحوية، دون تنفيذ الكود ودون إرساله إلى أي خادم.

مصغّر الأكواد

صغّر HTML وCSS وJavaScript بمحدّد لغة صريح، لكل لغة مُعالِج خاص يحافظ على البنية والنصوص داخل علامات الاقتباس، مع مقارنة الحجم قبل وبعد بالبايت والنسبة.

مشفّر HTML Entities

حوّل الأحرف الخاصة مثل & و < و > وعلامات الاقتباس إلى كيانات HTML آمنة، أو فكّ الكيانات المسماة والرقمية إلى النص الأصلي.

منسّق XML

نسّق XML وأعد إزاحته بمسافات متّسقة لتسهيل القراءة، مع كشف الوسوم غير المتوازنة وتحذيرك من السمات المكررة ومعالجة محتوى CDATA والنصوص بأمان.

دليل أنواع MIME

ابحث ثنائي الاتجاه بين امتداد الملف ونوع MIME المناسب، مع شرح عربي موجز لكل نوع ونسخ فوري للقيمة، وتغطية للصور والصوت والفيديو والمستندات.

دليل رموز حالة HTTP

دليل عربي شامل لرموز حالة HTTP مصنّف إلى معلوماتي ونجاح وتحويل وخطأ عميل وخطأ خادم، مع وصف لكل رمز ونصائح عملية للتعامل معه.

محلّل ترويسات HTTP

الصق ترويسات HTTP ودع الأداة تحلّلها وتشرح دور كل ترويسة في الأمن والكاش والترميز والمحتوى، وتنبّهك إلى الترويسات الأمنية الموصى بها الناقصة.

منسّق GraphQL

نسّق استعلامات GraphQL متعددة الأسطر بإعادة إزاحة الحقول والوسائط والتوجيهات والمتغيرات، ليصبح الاستعلام مقروءاً ومرتباً بسهولة.

مولّد متغيرات GraphQL

ولّد قالب JSON جاهزاً لمتغيرات عملية GraphQL من تعريفات المتغيرات فيها، مع جدول يوضّح النوع وهل هو مطلوب والقيمة الافتراضية.

عارض OpenAPI

الصق مستند OpenAPI 3 بصيغة JSON أو YAML لعرض ملخص المسارات والعمليات والمخططات، مع تنسيق الناتج ليكون قابلاً للقراءة والنسخ.

مولّد UUID

ولّد معرّفات UUID v4 عشوائية بضغطة واحدة، حتى 100 معرّف في المرة، مع نسخ كل النتيجة أو كل معرّف على حدة وتحميلها كملف نصي.

محوّل Unix Timestamp

حوّل Unix Timestamp إلى تاريخ ووقت، أو حوّل التاريخ إلى Timestamp بالثواني أو المللي ثانية، مع عرض التوقيت المحلي و UTC ومدة بقاء التاريخ من الآن.

مولّد Cron

أنشئ تعبيرات cron من حقول الجدولة وقوالب جاهزة، مع تحقق من الحدود وشرح عربي مفهوم يوضح متى يُنفَّذ في قواعد بياناتك ومهماتك المجدولة.

مولّد Unix Timestamp

حوّل التاريخ إلى Unix timestamp والعكس بالثواني أو المللي ثانية، مع عرض التوقيت المحلي و UTC وزر للحصول على الوقت الحالي.

محوّل أنظمة الأعداد

حوّل الأعداد بين الأنظمة من 2 إلى 36، مع دعم الأعداد الكبيرة والاختصارات الشائعة مثل 0x للنظام الست عشري و0b للثنائي.

منسّق Python

نسّق كود Python بإعادة ضبط المسافات البادئة والمسافات حول المعاملات والسلاسل، ليصبح الكود مقروءاً وموحّداً دون تغيير في دلالته.

مشغّل Python

شغّل برامج Python مبسطة داخل المتصفح عبر محاكي ذاتي يدعم الطباعة والمتغيرات والدوال والحلقات، مع حدود أمان للتكرار والزمن.
